# Code of Conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We want PantryTrack to be a welcoming project for everyone – experienced developers, students and restaurant owners who have never opened a pull request before.

## Expected behaviour

- Be respectful and patient, especially with newcomers.
- Give constructive, specific feedback on code, not on people.
- Accept that others may have different experience and opinions.
- Focus on what is best for the project and its users.

## Unacceptable behaviour

- Harassment, insults or discriminatory language of any kind.
- Personal or political attacks.
- Publishing other people's private information.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Report unacceptable behaviour to the project maintainer privately through GitHub. All reports will be reviewed and handled confidentially. Maintainers may remove comments, commits or issues that break this code, and may temporarily or permanently block repeat offenders.

## Scope

This code applies to all project spaces: issues, pull requests, discussions, the wiki and any other communication channel of the project.
