# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] – 2026-11-09

### Added
- Item management: add, list, remove, CSV import.
- Stock movements: receive, use, waste (with reason) and stock-take correction.
- Low-stock alerts and supplier-grouped re-order list with CSV export.
- Usage and waste report with waste rate per item, waste by reason and a waste-cost chart.
- Command-line interface `pantrytrack`.
- Test-suite (pytest) and GitHub Actions CI on Python 3.10–3.13.
- README, CONTRIBUTING, Code of Conduct, issue and pull request templates, MIT License.
